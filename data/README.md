# Data

Put Ninapro DB2 files in `data/ninapro/`, for example `data/ninapro/S1_E1_A1.mat`.
Use the `E1` files: they hold exercise B, which includes fist and the wrist movements.

Download them from the [Ninapro site](https://ninapro.hevs.ch) after registering and agreeing
to its terms. The data isn't committed to this repo (see `.gitignore`), because those terms
don't allow redistributing it.
